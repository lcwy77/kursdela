САЙТ «КУРС ДЕЛА»

Что где лежит
  content/   материалы, по одному файлу на текст
  static/    картинки
  build.py   сборка сайта
  docs/      готовый сайт, эту папку целиком заливают на хостинг

Перед первой выкладкой
  1. Открой build.py и в самом верху поменяй SITE_URL на свой домен
     (например https://kursdela.ru) и CONTACT на нужный контакт в телеграме.
  2. Запусти:  python3 build.py
  3. Отправь изменения в репозиторий: GitHub Pages раздаёт папку docs/ из ветки main.
  4. Добавь сайт в Яндекс Вебмастер и Google Search Console
     и укажи там карту сайта: https://твой-домен/sitemap.xml

Как добавить материал
  Скопируй любой файл из content/, дай ему имя латиницей через дефис
  (это станет адресом страницы), поменяй поля сверху и текст под чертой.
  Поля:
    title        заголовок на странице, можно яркий
    seo_title    заголовок для поиска: названия сторон и предмет спора
    date         дата публикации, ГГГГ-ММ-ДД ЧЧ:ММ
    updated      дата обновления (необязательно), тот же формат
    rubric       konflikty, ekonomika, politika, mir или ukraina
    description  одно-два предложения для поиска и ленты
    image        имя картинки из static/img (необязательно)
    src          источник: Название | ссылка. Строк src может быть несколько.
  Только для рубрики konflikty:
    a, b         стороны спора (b_rod, если название склоняется: «Совета ЕС»)
    sud          суд
    delo         номер дела
    cena         цена вопроса
    stadiya      стадия
  В тексте: абзацы разделяются пустой строкой, **жирный**, [ссылка](https://...).
  После правок снова запусти python3 build.py и залей docs/.

Когда в деле появляется новое решение
  Допиши абзац в тот же файл, поменяй stadiya и добавь строку updated.
  Адрес страницы не меняй: поисковики ценят страницы, которые живут и обновляются.
